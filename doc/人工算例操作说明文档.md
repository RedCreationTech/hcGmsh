## 2. 从空项目建立 V01

### 2.1 新建并保存项目

1. 启动 GMP-ISE。
2. 选择“文件 → 新建项目”。如果当前项目有未保存修改，先保存或另存。
3. 在顶部工作上下文条的“应用”下拉中选择 `DamSafetyApp-opt`，不要选择带 `[prototype]` 的档案。
4. 立即“另存为”，建议文件名为 `cdp-v01-manual.gmp.yaml`。后续生成的 `.i` 和工作目录会归属于这个项目。

检查点：顶部上下文和状态区域均显示 `DamSafetyApp-opt`，没有“未选择应用档案”提示。

### 2.2 导入 Exodus 输入网格

1. 切换到“网格（Mesh）”模块。
2. 点击“导入 Exodus 网格…”；也可使用“网格”菜单中的同名命令。
3. 选择：

   ```text
   /Users/a123/Desktop/code/damASR/docs/examples/cdp-v01-single-tension/input/uniaxial_compression_mesh.e
   ```

4. 在模型树选择新建的 Mesh 节点，打开 Mesh Workspace 的“分组与网格场 → 物理组”页签。统计表会以只读方式显示从 Exodus 导入的 `concrete_cube__concrete`、`bottom` 和 `top`；这些行来自输入网格 manifest，不能在此处编辑或删除。

预期值：

| 项目 | 预期 |
|---|---|
| 维度 | 3D |
| 节点 | 1331 |
| 单元 | 1000 |
| 单元类型 | HEX8 |
| 体组 | `concrete_cube__concrete` |
| 边界组 | `bottom`、`top` |
| `bottom` 节点数 | 121 |
| `top` 节点数 | 121 |

如果 Section 的“可选物理体”中没有 `concrete_cube__concrete`，或 BC 的“可选边界”中没有 `bottom/top`，停止验证并记录导入摘要，不要手工输入一个假组名绕过。

### 2.3 建立 CDP 材料

1. 切换到“材料（Material）”模块。
2. 点击“新建 CDP 材料”。
3. 在模型树右键新材料 →“重命名”，命名为 `concrete`。
4. 双击 `concrete`，或右键选择“编辑属性…”，打开标题为“Materials — concrete”的属性窗口。
5. 切换到“参数”页签。在“快捷参数”区域按以下顺序操作：

   1. 打开“模板”下拉框；
   2. 明确选择“CDP 混凝土（Abaqus）”；
   3. 点击右侧“应用模板”；
   4. 等待表单刷新，确认“类型”已经自动变为 `AbaqusCDP`。

   点击“应用模板”之前，“类型”可能仍显示 `ComputeElasticityTensor` 等旧值，这是尚未应用模板的正常中间状态。不要在“类型”下拉框中选择 `ComputeElasticityTensor`、`ComputeIsotropicElasticityTensor`、`ComputeSmallStrain` 或 `ComputeLinearElasticStress` 来代替 CDP；V01 必须是 `AbaqusCDP`，生成器随后会自动组成 elasticity、stress 和 CDP stress-update 三个材料对象。

6. 在刷新后的快捷参数中核对或填写：

| 字段 | 值 |
|---|---:|
| 类型 | `AbaqusCDP` |
| Young's Modulus (MPa) | `29791.5` |
| Poisson's Ratio | `0.2` |
| Dilation Angle (deg) | `36` |
| Eccentricity | `0.1` |
| fb0/fc0 Ratio | `1.16` |
| Tensile Meridian Ratio | `0.667` |
| Viscosity | `5e-4` |
| Tension Recovery | `0` |
| Compression Recovery | `1` |
| Max Substeps | `256` |

7. 依次点击四个 CSV 字段右侧的“浏览…”按钮，选择：

| UI 字段 | 文件 |
|---|---|
| Compression Hardening CSV | `compression_hardening.csv` |
| Compression Damage CSV | `compression_damage.csv` |
| Tension Stiffening CSV | `tension_stiffening.csv` |
| Tension Damage CSV | `tension_damage.csv` |

   四个文件均位于：

   ```text
   /Users/a123/Desktop/code/damASR/docs/examples/cdp-v01-single-tension/input/
   ```

8. 在窗口上方“可选物理体”中单击选择 `concrete_cube__concrete`，然后点击“应用所选物理体”。只选择这一项。
9. 应用后核对：`concrete_cube__concrete` 仍保持选中；在高级参数表中，`block` 应为 `concrete_cube__concrete`。模板应用不会代替物理体指派，这一步不能省略。
10. 保持“高级参数”勾选，在下方参数表确认以下预设仍存在：

| 参数 | 值 |
|---|---:|
| `maximum_strain_increment` | `2.5e-5` |
| `enable_performance_diagnostics` | `true` |
| `unit_factor_stress` | `1000000` |

11. 切换到“校验”页签，确认没有缺少四张 CSV、材料参数或未知物理体的错误。
12. 点击右下角“确定”保存；不要点击“取消”。回到模型树后，`concrete` 应显示为“就绪”。

注意：Young's Modulus 在表单按 MPa 显示，保存到模型参数和求解输入时应为 `29791500000` Pa。不要在 MPa 输入框填写 `29791500000`。

本步骤的最终检查点：

```text
模板 = CDP 混凝土（Abaqus）
类型 = AbaqusCDP
block = concrete_cube__concrete
四张 CSV 均已选择
材料节点 concrete = 就绪
```

### 2.4 建立 Section 并指派体组

1. 切换到“截面（Section）”模块，点击“新建实体截面”。
2. 将新节点重命名为 `concrete_section`。
3. 在属性表单设置：

| 字段 | 值 |
|---|---|
| Type | `SolidSection`（只读） |
| Material | `concrete` |

4. 在“可选物理体”中只选择 `concrete_cube__concrete`。
5. 点击“应用所选物理体”。

检查点：“Assigned Physical Volumes”只读框显示 `concrete_cube__concrete`。

### 2.5 建立 QuasiStatic Physics

1. 在模型树右键 `Physics` 根节点 →“添加 Physics”。
2. 名称输入 `concrete`。
3. 选择新节点并设置：

| 字段 | 值 |
|---|---|
| Action | `QuasiStatic` |
| Block | `concrete_cube__concrete` |
| Strain | `SMALL` |
| `volumetric_locking_correction` | `true` |
| `incremental` | `true` |
| `add_variables` | `true` |
| `save_in_resid` | `true` |

4. `generate_output` 填入以下 16 项，空格分隔：

```text
stress_xx stress_xy stress_xz stress_yy stress_yz stress_zz strain_xx strain_xy strain_xz strain_yy strain_yz strain_zz max_principal_stress mid_principal_stress min_principal_stress vonmises_stress
```

如果 Block 字段支持下方体组选择，优先选择 `concrete_cube__concrete` 并点击应用，不要拼写输入不存在的体组。

### 2.6 建立加载函数

1. 在模型树右键 `Functions` 根节点 →“添加 Functions”。
2. 名称输入 `top_displacement`。
3. 设置：

| 字段 | 值 |
|---|---|
| Type | `ParsedFunction` |
| Expression | `2.5e-05*t` |

`X Values`、`Y Values` 仅用于 PiecewiseLinear，本算例保持为空。

### 2.7 建立四个边界条件

每次均在模型树右键 `BC` 根节点 →“添加 BC”，输入下表名称；在属性表单中设置类型、变量和值/函数，再从“可选边界”选择指定边界并点击“应用所选边界”。

| 名称 | Type | Variable | Boundary | Value | Function |
|---|---|---|---|---:|---|
| `bottom_z` | `DirichletBC` | `disp_z` | `bottom` | `0` | 留空 |
| `top_x_gauge` | `DirichletBC` | `disp_x` | `top` | `0` | 留空 |
| `top_y_gauge` | `DirichletBC` | `disp_y` | `top` | `0` | 留空 |
| `top_z` | `FunctionDirichletBC` | `disp_z` | `top` | 留空 | `top_displacement` |

检查点：`top_z` 的 Function 下拉中能选择已有的 `top_displacement`；四个 BC 均不显示失效状态。

| Solve Control | `nl_rel_tol` | `1e-9` |

### 2.9 建立输出请求

1. 在模型树右键 `Outputs` 根节点 →“添加 Outputs”。
2. 名称输入 `v01_outputs`。
3. 在“Field Output”中勾选全部 8 项：

```text
DamageC DamageT kappa_c kappa_t local_iterations accepted_substeps jacobian_fallbacks integration_microseconds
```

4. 在“History Output”中设置：

| 字段 | 值 |
|---|---|
| History Preset | `cdp_uniaxial_z` |
| Reaction Force | `false` |
| Displacement Avg | `false` |
| Extremum | `false` |

`cdp_uniaxial_z` 是 GMP-ISE 内置的 V01 单轴 Z 向 CDP 历史输出预设，不是从导入网格或模型中读取的对象。它固定生成本算例的 13 个 Postprocessor，其中反力/位移请求直接引用网格中已存在的 `top` 和 `bottom` 边界组。

顶部“可选边界分组”只服务于 `custom` 模式下的 Reaction Force / Displacement Avg 通用请求；选择 `cdp_uniaxial_z` 时该值不参与生成。本步不选任何边界，保持“待应用选择：（无）”。三个通用开关保持 `false`，避免再生成一组重复的自定义请求。

5. 在“Times”中设置：

| 字段 | 值 |
|---|---:|
| Enable Times | `true` |
| Times Name | `field_output_times` |
| `start_time` | `0` |
| `end_time` | `1` |
| `time_interval` | `0.01` |

6. 在“Output Files”中设置：

| 字段 | 值 |
|---|---|
| Exodus | `true` |
| CSV | `true` |
| `file_base` | `uniaxial_tension_single` |

`file_base` 是求解结果文件的基名/前缀，不是模型对象引用，因此使用文本输入框而不需要下拉选择。在输入框中手工输入 `uniaxial_tension_single`，不加 `.e` 或 `.csv` 扩展名。同步后，`[Outputs/field_exodus]` 和 `[Outputs/history_csv]` 都应包含：

```text
file_base = uniaxial_tension_single
```

检查点：Outputs 节点状态为“就绪”不代表 `file_base` 已填写，该字段对 MOOSE 属于可选项；V01 人工复现为了与标准算例输出命名一致，必须按上述值显式填写。

## 3. 同步与生成输入核对

1. 保存项目。
2. 切换到“属性（Property）”模块，点击“同步模型到输入”；也可在“作业（Job）”模块点击“同步到输入”。
3. 打开生成输入查看区。
4. 逐项核对以下关键结构。对象名可有等价前缀，但类型、引用和数值必须一致：

| 生成块 | 必须核对的内容 |
|---|---|
| `[Mesh/file]` | 指向所选 `uniaxial_compression_mesh.e` |
| `[GlobalParams]` | `displacements = 'disp_x disp_y disp_z'` |
| `[Physics/SolidMechanics/QuasiStatic/concrete]` | block、SMALL、volumetric locking、16 项 `generate_output`、`save_in` |
| `[AuxVariables]` / `[AuxKernels]` | 3 个 `resid_*` 加 8 个 CDP 场量；CDP 场量作用于 `concrete_cube__concrete` |
| `[Functions]` | `top_displacement` 和 `2.5e-05*t` |
| `[BCs]` | 四个 BC 的变量、边界、值/函数与上表一致 |
| `[Materials]` | `ComputeIsotropicElasticityTensor`、`ComputeMultipleInelasticStress`、`AbaqusCDPStressUpdate` 三件套及四个 CSV basename |
| `[Postprocessors]` | 下列 13 个对象全部存在 |
| `[Executioner]` | Transient、Newton、容差、IterationAdaptiveDT 参数 |
| `[Preconditioning/smp]` | `type = SMP`、`full = true` |
| `[Times/field_output_times]` | 0～1 s、0.01 s 间隔 |
| `[Outputs]` | Exodus、CSV、同步时间对象和 `uniaxial_tension_single` |

max_damagec

禁止为了通过核对而直接修改生成的 `.i`。如果有差异，应返回对应模型树对象修改属性后重新同步。
