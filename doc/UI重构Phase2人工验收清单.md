# UI 重构 Phase 2 人工验收清单

> 当前验收范围：I-03“统一模块、树、表单与舞台的交互状态”（I-01 / I-01A / I-02 已通过并关闭）
> 前置条件：Phase 1 人工验收已通过
> 当前结论：I-03 自动回归与人工验收已于 2026-09-06 全部通过

## 验收准备

1. 启动 `./build/gmp_ise`。
2. 打开一个含 Material 节点的项目，或在材料根节点下新建一个材料。
3. 记住当前项目标题栏是否已带 `*`，便于检查未提交编辑是否误改保存状态。

I-02 另需准备：

1. 优先打开一个已有的 `.gmp.yaml` 项目，项目中至少有 Part、Material；如需验证舞台双向定位，Part 应由拉伸/旋转等特征产生并正在舞台显示。
2. 确保 MOOSE 设置中已经填写 `.i` 输出路径；不要求真正提交计算作业。
3. 如项目已有 Job/Result，可直接使用；否则可在对应根节点下新增临时条目完成导航验证，验收后不保存项目即可。

I-03 另需准备：

1. 项目中至少各有一个 Part、Material 和 Sketch；建议为 Part 配置有效的 `gmsh_volume_tag`，便于验证舞台反向定位。
2. Mesh 工作窗中配置一个可生成的简单几何和 `.msh` 输出路径；如网格生成过快，可适当降低网格尺寸以观察运行态。
3. Job 长任务验证为可选增强项；若本机 MOOSE 可执行文件可用，可再用一个耗时数秒的 `.i` 重复验证运行/停止按钮。

## TEST-P2-I01-01 单击只选择，显式命令才编辑

1. 单击一个 Material 子节点。
2. 确认节点高亮，顶部“当前对象”同步，但没有弹出编辑窗。
3. 分别用双击、`Model → 编辑属性...`或 `Enter` 打开属性窗（每次检查后取消）。

通过标准：单击不弹窗；三个显式入口打开同一类型的表单。

## TEST-P2-I01-02 弹窗语义和舞台位置

1. 双击 Material 子节点。
2. 确认标题为“编辑材料 — <对象名>”，并有“确定/取消”。
3. 确认窗口默认出现在中央舞台偏左，可拖动，舞台仍可见。
4. 在表单打开时尝试点击另一个树节点。

通过标准：表单为模态窗，处理完当前编辑前不能切换树对象；没有恢复永久右栏。

## TEST-P2-I01-03 取消、关闭和 Esc 丢弃缓冲

1. 打开表单，修改名称和至少一个参数，不点“确定”。
2. 点“取消”，确认树节点名称和参数不变，项目标题的 `*` 状态与打开前一致。
3. 再次打开并修改，分别用标题栏关闭和 `Esc`重复检查。

通过标准：三种取消方式均不写回、不产生脏状态。

## TEST-P2-I01-04 校验失败阻止提交

1. 打开表单，清空“名称”，点“确定”。
2. 确认弹窗不关闭，错误文本可见，光标定位到名称。
3. 恢复名称，对当前类型再清空一个必填参数（如 Material 的 `type`），再点“确定”。

通过标准：非法数据不写回；表单切换到对应页并尽可能聚焦首个错误字段。

## TEST-P2-I01-05 确定后一次写回

1. 打开表单，将名称改为一个不重复的合法名称，修改一个参数。
2. 在点“确定”前，观察左侧树和项目标题，确认它们未变。
3. 点“确定”。

通过标准：表单关闭后树名称、参数和当前对象同步到新值，项目标记为已修改。

## TEST-P2-I01-06 尺寸记忆、可见性与专用编辑器回归

1. 调整 Material 表单尺寸后取消，重新打开，确认同类型尺寸恢复。
2. 将表单拖到屏幕边缘后关闭，改小主窗口再打开，确认弹窗中心回到舞台可见区。
3. 双击 Sketch 和 Part 子节点，确认仍分别打开草图和部件专用编辑器。
4. 打开 Job/Results，确认仍使用各自的独立工作窗，中央舞台不被替换。

通过标准：同类型尺寸可恢复，无越界不可恢复窗口，Phase 1 既有专用编辑和独立工作窗无回归。

## TEST-P2-I01-07 模块工作窗无双层滚动

1. 依次打开 Material、Section、Step、Load、Mesh 等模块工作窗。
2. 检查窗口默认状态下的标题说明、主操作、当前对象列表和底部对象操作。
3. 缩小窗口高度后再次检查滚动行为。

通过标准：默认尺寸内主要交互均可见；主操作横向排列；Mesh 可通过“模型/几何/分组与网格场/网格/日志”切换全部功能；任一页面不出现内外并存的两条竖向滚动条；缩小时至多出现一层内容滚动。

## TEST-P2-I01-08 属性与部件编辑页签布局

1. 双击 Material 子节点，确认属性窗显示“常规/参数/校验/预览”四个页签。
2. 切换四个页签，确认字段、错误汇总和预览均可访问，底部“确定/取消”始终可见。
3. 新建或双击 Part，确认部件窗显示“拉伸/旋转/放样/扫掠”四个页签。
4. 切换四个部件页签，确认每个特征的字段和执行按钮默认可见。

通过标准：表单标签与字段同排且不被裁切；页签切换正常；没有为了访问底部按钮而使用第二条竖向滚动条。

## TEST-P2-I01-09 Job、Visualization、Results 工作窗布局

1. 打开 Job 工作窗，切换“作业列表/MOOSE 设置”。
2. 在 MOOSE 设置中依次切换“算例设置/执行配置/输入文件/运行日志”，检查底部“运行/检查输入/停止”始终可见。
3. 打开 Visualization 与 Results 工作窗，切换其全部页签。
4. 关闭并重新打开三个工作窗，确认尺寸合理且未超出当前屏幕。

通过标准：复合功能通过页签访问，默认窗口内无双层滚动、无底部操作裁切；重复打开仍为单实例且尺寸可用。

## TEST-P2-I02-02 Model/Results 导航与状态展示

1. 观察左侧顶部，确认只有“模型/结果”两个导航页签，没有 Material Library 空页签。

3. 检查“对象/状态”两列：空根节点、已配置对象、网格、作业和结果均同时显示状态图标与状态文字。

通过标准：过滤结果正确且不改变父子关系、对象数量、参数或项目脏状态；清除后树完整恢复。

## TEST-P2-I03-03 命令可用性与禁用原因

1. 选择 Parts 根节点，检查“编辑属性”菜单/工具栏命令。

2. 确认模型树反向定位、顶部“当前对象”和底部“上下文”同步。
3. 检查“清除选择”命令已启用并执行。
4. 再次检查“清除选择”命令状态。

通过标准：舞台只维护当前一组选择；拾取后树与上下文同步，清除后舞台选择集合清空且“清除选择”重新禁用，不影响模型数据。

## TEST-P2-I03-05 Mesh/Job 长任务运行态与防重复

1. 在 Mesh 工作窗启动一次可观察到耗时的网格生成。
2. 生成期间检查 Mesh 工作窗的生成按钮、顶部“生成网格”、作业“运行/检查输入”等互斥命令。
3. 尝试再次触发生成（包括快捷键 `Ctrl+M`）。
4. 等待生成成功或失败，再检查按钮、Tooltip 和状态栏消息。
5. 若本机 MOOSE 可运行，再启动 Job，重复检查“运行/检查输入/停止”及 Job 工作窗的“运行/重试/停止”。

通过标准：运行期间按钮显示“正在生成…”或“运行中…”，重复入口禁用；Mesh 与 Job 不会互相并发提交；完成后命令恢复并明确显示成功/失败消息；Job 运行时仅“停止”可用。

## TEST-P2-I03-06 特征写回当前 Part 且不重复创建部件

1. 新建并完成一个闭合草图，再通过“新建部件”选择该草图创建 `part_1`。
2. 保持 `part_1` 为当前对象，在 Part 工作窗选择该草图并执行拉伸。
3. 检查 Parts 和 Features 根节点、顶部“当前对象”以及 Part 工作窗标题。
4. 在同一个 `part_1` 上再次执行一次特征操作。
5. 选择 Parts 根节点后尝试执行特征操作。

## TEST-P2-I03-07 草图二维视口交互与撤销重做

1. 新建或双击一个含图元的 Sketch，进入草图编辑；在舞台左侧依次选择“草图选择”“移动图形”“缩放”。
2. 用“草图选择”单击一个图元，再按住 `Shift` 单击另一个图元；执行“清除选择”。
3. 使用鼠标中键拖动整体视图；选择“缩放”后按住左键上下拖动，并验证鼠标滚轮缩放；点击“适配窗口”。
4. 新绘制一个图元，按 `Cmd+Z`（macOS）或 `Ctrl+Z`（Windows/Linux）撤销，再按 `Cmd+Shift+Z`（macOS）或平台标准重做组合键恢复。
5. 完成编辑回到只读草图预览，重复选择、清除、中键平移、缩放和适配窗口；点击移动、绘制或删除工具。

通过标准：选择可高亮单个/多个草图图元并可清除；中键平移、拖动缩放、滚轮缩放和适配窗口均改变相机且不修改草图；撤销/重做按钮与快捷键在浮动草图编辑窗获得焦点时都生效；只读预览允许查看和选择，选择修改工具时自动进入当前草图的编辑会话，再执行移动、新增或删除。

## TEST-P2-I03-08 草图图元拖动与工具状态互斥

3. 分别对外部圆及圆弧重复拖动；再用“选择”先多选两个完整图形，切回“移动图形”并拖动其中一个。
4. 在“移动图形”“缩放”“选择”之间来回切换，观察舞台左栏和 Sketch Editor 工具按钮的高亮状态。
5. 拖动一个图形后执行撤销和重做；完成编辑进入只读预览，再点击“移动图形”。

通过标准：按下移动工具后可命中任意完整图形并立即选中；拖动只改变命中/已选图形的位置，不平移整体视口，圆/圆弧的半径和角度不变；多选时可整体移动选中集合；移动、缩放、选择任一时刻只高亮一个主操作且编辑窗状态同步；一次拖动对应一步撤销；只读预览点击移动后自动进入当前草图编辑，并保持移动工具生效。

## TEST-P2-I03-09 逻辑图形、子图元与混合多选移动

1. 新建一个草图，绘制矩形、圆、圆弧和若干独立直线；保存、关闭并重新打开草图。
2. 使用“选择”或“移动图形”单击矩形任意一条边，观察高亮范围并拖动。
3. 按住 `Option`（macOS）或 `Alt`（Windows/Linux）单击矩形的一条边，再拖动该边。
4. 按住 `Shift` 依次点击矩形和圆，拖动其中任一已选图形；再使用 `Shift+Option/Alt` 选择矩形的多条边并拖动。
5. 打开一个由旧版本保存、未包含 `shape_id` 的矩形草图，重复步骤 2。

通过标准：默认命中矩形任意边时 4 条边作为一个逻辑图形共同高亮和移动；`Option/Alt` 可只选中、移动一条子边；`Shift` 可组合多个完整图形，`Shift+Option/Alt` 可组合多个子图元；多选集合整体保持相对位置；新草图保存重开后分组不丢失，旧矩形可从重合约束恢复为完整图形。

## TEST-P2-I03-10 草图工具多入口状态同步

1. 完成草图编辑并停留在只读预览，点击舞台左侧“移动图形”（四向箭头）。
2. 确认自动打开当前草图编辑器，并观察顶部拾取、左侧选择/移动、Sketch Editor 选择/移动的高亮。
3. 点击顶部“拾取”，再依次从左侧和 Sketch Editor 切换选择、移动、直线及缩放。
4. 在每次切换后到视口实际单击或拖动，确认执行的交互与高亮工具一致。

通过标准：预览态选择修改工具会进入编辑而非退回点选；顶部拾取、左侧舞台工具和 Sketch Editor 由同一当前工具状态驱动，任何时刻只有一个主交互高亮；顶部拾取切换到选择，移动/绘制/缩放可从任一对应入口切换成功；点击或拖动悬浮工具组不会在鼠标释放时把当前工具重置为选择。

## TEST-P2-I03-11 草图工具持续高亮与编辑窗内容适配

1. 打开 Sketch Editor，依次点击直线、圆、圆弧和矩形等绘制工具；每次在舞台完成一个图元后继续观察工具按钮。
2. 在 Sketch Editor 与 Part、Material、Mesh 等工作窗之间切换，比较窗口默认尺寸和重新打开后的尺寸。
3. 手动调整 Sketch Editor 大小后关闭并重新打开；再打开其他模块工作窗。
4. 观察底部撤销/重做和“完成编辑”按钮的排列及宽度。

通过标准：当前绘制工具在再次切换前始终以蓝底白字高亮，并显示独立“当前工具”状态条；绘制完成不会取消高亮；工作窗只由当前页面的尺寸提示决定，不再被隐藏的复杂页面撑大；Sketch Editor 默认约 `680×350`、最小约 `640×320`，拥有独立的尺寸/位置记忆且不改变其他模块工作窗；工具与约束双栏紧凑排列，“完成编辑”位于底部操作行且不横跨整窗。

## TEST-P2-I03-12 删除模型对象同步清理 3D 舞台

1. 新建闭合草图，通过拉伸生成一个 Part，确认 3D 舞台显示对应网格。
2. 删除该 Part 所引用的草图，观察模型树和 3D 舞台。
3. 重新建立草图和 Part 并完成拉伸，再删除 Part，检查 Features 根节点和 3D 舞台。
4. 清空后重新打开任意有效网格，确认模型可再次正常显示。

通过标准：删除当前预览草图会立即退出其二维预览；删除被 Part/Feature 引用的草图、删除 Part 或删除产生当前网格的 Feature 时，旧网格、节点、轮廓、选择高亮、标尺和文件监听同步从舞台清除；删除 Part 同时删除属于它的 Feature 历史，不留下孤立 Feature；清空只解除项目引用与显示状态，不物理删除已经生成的 BREP/MESH 文件；后续重新载入网格仍可正常显示。

## TEST-P2-I03-13 多轮廓 Part 跨模块切换保持完整

1. 在同一草图中绘制两个互不相交的闭合图形，例如两个圆或一个圆加一个矩形。
2. 新建一个 Part，以该草图沿 Z 轴拉伸，确认舞台同时显示两个独立 3D 实体。
3. 切换到 Sketch 模块并预览该草图，再切回 Part 模块并选中原 Part。
4. 重复 Sketch/Part 切换，并在模型树中分别单击该 Part 与其 Feature。

通过标准：一次多轮廓特征仍对应一个 Part，但 Part/Feature 保存本次生成的全部 Volume 标签；初次拉伸、切换到 Sketch 再返回 Part、重复选中 Part/Feature 后，两个 3D 实体始终同时可见，不得按首个 `gmsh_volume_tag` 将其余实体隐藏；旧项目只有单标签但保存了 Part 自有 MESH 时，也应恢复完整网格。

## TEST-P2-I03-14 树对象名称唯一性与冲突重试

1. 在 Parts 下已有 `part_1` 时，通过模型树“添加”再次使用默认名称 `part_1` 并点击确认。
2. 观察错误提示和命名弹窗，改为一个未使用的名称后再次确认。
3. 在 Sketches、Materials、Sections、Steps、BC、Loads 等其他根节点重复同名新增操作。
4. 对现有对象执行重命名，输入同根节点下已有名称；再连续复制同一个对象两次。

通过标准：名称会去除首尾空白且不能为空；同一根节点的直接子对象名称必须唯一。新增或重命名发生冲突时不得创建/改名，命名弹窗保持打开、显示明确错误并保留继续输入能力；改成唯一名称后才提交。复制及其他无命名弹窗的自动创建路径必须生成唯一后缀，不得静默产生重名。不同根节点之间允许使用相同名称。

## TEST-P2-I04-01 Mesh 专用工作窗与网格生成

3. 在窗口内确认“模型/几何/分组与网格场/网格/运行日志”五个页签完整；设置生成参数并执行一次网格生成，确认进度、质量摘要和日志正常更新。

通过标准：Mesh 页面唯一归属 `meshWorkspaceWindow`，Module Workspace 中只剩说明与打开按钮的 launcher 页；三处入口均激活同一窗口；生成参数、进度、质量摘要和舞台联动与迁移前一致。

通过标准：详细参数实时驱动中央舞台渲染；重复打开只激活同一实例；关闭窗口不改变舞台当前显示状态。

3. 重新打开 Job 工作窗，确认作业状态、进度和运行日志完整可查看。

通过标准：关闭窗口不停止作业、不丢失日志；重新打开后状态与日志连续；运行期间共享“停止”命令保持可用。

## TEST-P2-I04-05 Results“新建对比窗口”多实例

通过标准：文件清单与 LIMS 制品库一致（运行中为实时快照）；下载不覆盖、可追踪；Exodus 结果进入 Results 体系；远程取消有确认且状态闭环。
