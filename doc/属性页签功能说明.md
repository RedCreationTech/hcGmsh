# "属性"页签（Property Module）功能说明

> 版本：2026-09-06。对应实现：`src/PropertyEditor.cpp` / `include/gmp/PropertyEditor.h`（编辑器本体）、`src/FloatingPropertyForm.cpp`（模态浮动表单壳）。

## 1. 功能目的

属性编辑以**模态浮动属性表单**进行：在左侧模型树中**单击只选择**节点；**双击**（或按 `Enter`、右键菜单 `Edit Properties...`）打开该节点的浮动属性表单，展示并编辑其身份信息、参数集合与校验结果。Module Workspace 中的"属性"模块页仍提供当前选中节点的**只读上下文浏览**。它是"以模型树为单一数据源"架构下的通用节点编辑器——所有模块（材料、截面、分析步、草图、部件、特征等）的节点参数最终都以键值对形式存于模型树节点的 `params` 中，属性表单是这些参数的统一入口。

适用场景：

- 双击材料/截面/分析步等节点，用**快捷表单**编辑常用字段（比手改键值直观）；
- 双击任意节点，用**高级参数表**直接增删改键值（全类型通用）；
- 检查节点配置是否缺失必填项（校验页签的校验汇总），并定位有问题的节点；
- 查看节点的数据快照（预览页），确认"这个节点现在到底存了什么"。

## 2. 编辑语义：确定写回 / 取消丢弃

表单打开时会把整棵模型树克隆到内部**编辑缓冲**，表单内的所有修改只作用于缓冲：

- **确定**：先执行校验（名称唯一性、按类型的必填/参数规则），通过后把缓冲节点的名称与参数**一次性写回**模型树并标脏项目；校验未通过则表单保持打开，可修正后再次确认；
- **取消**、`Esc` 或关闭窗口：丢弃缓冲中的全部修改，模型树不变，**不改变项目脏状态**。

表单含**常规 / 参数 / 校验 / 预览**四个页签，详解如下。

## 3. 四个页签详解

### 3.1 常规（General）

节点的**身份信息**（标签与值同行显示；参数页的快捷表单则为标签在控件上方）：

> 说明：此前 macOS 下 QMacStyle 强制表单"标签在字段上方"，整列看起来像空行，属布局误读；2026-08-12 已将常规页改为标签与值同行。

| 字段 | 含义 |
|---|---|
| Kind（类型） | 节点所属的模型树根类别（Materials / Sections / Sketches / Parts / Features …） |
| Status（状态） | 节点 params 中的 `status`/`state` 字段（Mesh/Jobs/Results 类节点有；草图/部件/特征类节点无此字段，显示 `-`） |
| Name（名称） | 节点名，可编辑（子节点） |
| Summary（摘要） | 按类型生成的关键信息摘要（见下表） |

Summary 摘要行（2026-08-12 新增）针对 CAD 相关节点给出"从哪来"的信息：

| 节点类型 | 摘要内容示例 |
|---|---|
| Features（特征，建模历史） | `Extrude, sketch: sketch_1, distance=10`（操作类型 + 来源草图 + 关键参数） |
| Parts（部件，3D 产物） | `sketch: sketch_1, feature: feature_1, gmsh volume 1`（来源草图 + 产出它的特征） |
| Sketches（草图） | `plane: XY, entities: 4, constraints: 4`（平面 + 图元/约束数量；空草图显示 empty sketch） |
| 其他类型 | `-` |

### 3.2 参数（Parameters）

节点的**参数编辑区**，分四层：

1. **Quick Parameters（快捷表单）**：仅以下类型有定制表单（下拉/模板默认值）：
   `Materials`（本构类型与属性）、`Sections`（截面-材料绑定）、`Steps`（时间步/求解器）、`BC`（边界条件）、`Loads`（载荷）。
   其余类型（Sketches/Parts/Features/Datums/Variables/Functions/Outputs/Interactions/Mesh/Jobs/Results）此区隐藏，直接用下面的高级参数表。
2. **Groups（分组）**：仅 Section 类节点使用，用于绑定网格物理分组。
3. **Advanced Parameters（高级参数表）**：任意键值对的直接编辑（增/删/改），与快捷表单**双向同步**（Sync 下拉可改同步策略）。Features 节点的 `sketch`、`distance`、`brep` 等就在这里可见可改——注意：**改参数不会触发特征重建**（参数化重算引擎属于后续版本）。
4. **缺失项提示**：按类型的必填规则检查当前节点，缺失必填字段时显示红色 `Missing required fields: …`；全树校验汇总移至"校验"页签（见 3.3）。

### 3.3 校验（Validation）

按类型的必填规则对**全树**节点做校验汇总：`Node / Issues` 表格，可过滤"仅当前类型（Current Type Only）/仅问题项（Only With Issues，默认勾选）"，`Refresh` 刷新，`Go To Node` 跳转到问题节点。典型规则：Transient 步要求 `dt>0, end_time>0`；FunctionDirichletBC 要求 `function`；BodyForce 要求 `value` 或 `function`。

### 3.4 预览（Preview）

选中节点的**数据快照**，为**自定义只读格式**，结构如下：

```
Node: feature_1
Kind: Features
Status: -

[Input Preview]
  # name: feature_1
  brep = /path/to/extrude_xxx.brep
  distance = 10
  sketch = sketch_1
  type = Extrude

[Validation]
  No issues.
```

**它不是 MOOSE 输入文件（.i）的内容**——它只是把该节点 params 的键值对按类 MOOSE 风格排版（对 Materials/Sections/Steps/BC/Loads/Functions/Variables 会多套一层 `[Block]` 壳，因为它们最终会进入 .i 的同名 block）。预览页顶部标题已标注 `node data, not MOOSE input`。

真正的 MOOSE 输入文本在：**菜单 模型 → 同步模型到输入** 生成，经"作业"模块提交运行；草图/部件/特征（CAD 侧）当前**不参与** .i 生成，它们经 OCC 建模 → gmsh 网格后，以网格（physical groups）身份进入仿真流程。

## 4. 数据流与持久化

- 单一数据源：模型树节点（`params` 键值对 + `kind` 类别）。
- 表单内的编辑先写入编辑缓冲；"**确定**"校验通过后一次性写回节点参数并标脏项目，"**取消**"/`Esc`/关闭窗口则丢弃修改且**不改变项目脏状态**；保存项目时随 `.gmp.yaml` 持久化（所有值按字符串序列化）。
- 草图的几何数据（图元/约束）以 YAML 字符串存于草图节点的 `params["data"]`，同样在预览/高级参数表中可见（内容较长，建议用草图编辑器修改而非手改）。
- 特征/部件的几何产物不内嵌项目文件：brep 落盘于项目目录 `features/`（未保存项目在临时目录），节点仅存路径与 gmsh 实体 tag。

## 5. 已知边界

- 快捷表单仅覆盖 5 个 MOOSE 相关类型；CAD 新类型（Sketches/Parts/Features/Datums）暂无快捷表单（特征参数在高级表中编辑，且不触发重建）。
- 状态（Status）字段只对 Mesh/Jobs/Results 类节点有意义。
- 预览页为只读；要改数据请回"参数"页签。
- 双击 Sketches 节点打开草图编辑器、Parts 节点打开 Part 编辑器、Mesh/Jobs/Results 节点打开对应工作窗，均不打开属性表单。
