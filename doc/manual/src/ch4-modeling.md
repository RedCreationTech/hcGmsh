# 建模

本章介绍前处理建模的三个环节：二维草图、部件特征建模与装配实例。建模完成后，请继续阅读 [材料 · 截面 · 物理](ch5-materials.html) 与 [网格](ch7-mesh.html)。

## 草图：工具、约束与尺寸

切换到**草图（Sketch）**模块，在模块工作窗点击**新建草图（New Sketch）**即可创建草图；双击草图（或选中后点「打开所选草图」）进入二维编辑会话，浮动草图编辑器提供以下能力：

- **绘制工具（Tools）**：选择（Select）、移动（Move）、直线（Line）、圆（Circle）、圆弧（Arc）、矩形（Rectangle）与删除（Delete）。直线端点自动吸附到已有特征点；矩形一次生成四条端点重合的直线。当前工具以蓝底白字高亮，完成一次绘制后保持生效，直到主动切换；
- **几何约束（Constraints）**：水平（Horizontal）、竖直（Vertical）、平行（Parallel）、垂直（Perpendicular）与共点（Coincident，把两个图元最近的端点吸附到一起）。先选图元、再点约束按钮；
- **驱动尺寸（Dimension）**：在数值框输入目标值后，选中线点**Add Distance** 添加距离尺寸，选中圆或弧点**Add Radius** 添加半径尺寸，草图求解器会据此反算几何；
- **选择与编辑**：单击选择完整图形，`Shift+单击`多选；按住 `Option/Alt` 可下钻到单边等子图元；Delete 键删除当前选择。鼠标中键平移视图，滚轮缩放；
- **撤销与完成**：撤销（Undo）/重做（Redo）以一次草图修改为一步（快捷键 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z）；点**完成编辑（Finish Edit）**返回三维视图，舞台保留只读预览。

草图支持嵌套轮廓（如外矩形内套圆孔），供拉伸等特征直接生成带孔实体。

## 部件：拉伸、旋转、放样与扫掠

切换到**部件（Part）**模块。点击**新建部件（New Part）**创建部件节点，中部**特征（Feature）**区以页签组织四类成形方式，均从草图轮廓出发：

- **拉伸（Extrude）**：选择轮廓草图与距离，点**沿 +Z 拉伸（Extrude along +Z）**把闭合轮廓沿 +Z 拉伸成实体，负距离反向；
- **旋转（Revolve）**：选择轮廓草图与角度，点**绕 Y 轴旋转（Revolve about Y axis）**绕 Y 轴旋转成形；
- **放样（Loft）**：选择两个截面草图，第二截面按给定高度抬升，点**放样（Loft）**生成实体；
- **扫掠（Sweep）**：选择轮廓草图与路径草图，点**扫掠（Sweep）**沿路径扫掠成形。

一个部件可以包含同一次特征生成的多个独立体（如相离轮廓拉伸出的多个方块）。删除部件会同步删除其特征历史并清空三维舞台，但不会删除磁盘上已生成的几何文件。

## 装配实例

切换到**装配（Assembly）**模块，可以把已有部件放置为实例并组装：

- **创建实例（Create Instance）**：在实例表单中选择部件，配置平移、按 X → Y → Z 顺序应用的角度制旋转、三轴缩放、可见性与排列顺序；
- **构建装配（Build Assembly）**：把可见实例的变换落实到 Gmsh，并为每个实例生成 `<实例名>` 顶维物理组和 `<实例名>_surface` 边界组，供 [网格](ch7-mesh.html) 与边界条件引用；
- 修改源部件或实例参数后，装配及下游网格、输入与作业会被标记为过期；项目保存重开后实例引用与变换参数保持不变。
