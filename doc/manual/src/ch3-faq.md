# 常见问题

本章汇总新用户最常遇到的问题。仍找不到答案时，请通过**文件（File）→ 导出调试包（Export Debug Bundle...）**导出诊断信息并随问题一并反馈。

## 用户手册从哪里打开

- 按 **F1**，或选择**帮助（Help）→ 用户手册（User Manual）**；
- 手册窗口左侧为目录与索引页签，点击条目即可跳转到对应章节。

## 工作窗被关了，在哪里重新打开

所有工作窗都可从**视图（View）**菜单找回：打开模块工作窗、打开网格工作窗、打开作业工作窗、打开结果工作窗等。双击模型树中的 Mesh 子节点也会直接打开网格工作窗。

## 图标按钮认不全怎么办

把鼠标悬停在按钮上停留片刻，会弹出文字提示（Tooltip）说明按钮用途；菜单命令与多数按钮一一对应，记不住图标时可以从菜单执行同一命令。

## 界面怎么切换成中文

选择**设置（Settings）→ 语言（Language）→ 中文**，界面即时切换为中文，无需重启；随时可切回 English。

## 网格生成失败如何排查

按顺序检查：先看底部**消息控制台（Console）**中的错误信息；再确认网格工作窗「模型/几何」页中已加载几何或勾选「使用示例盒」；若用到物理组，确认「物理组与网格场」页中物理组已生成。修改后再次点击「生成网格」。

## 提交作业前需要什么条件

先通过**作业（Job）→ 校验工作流（Validate Workflow）**做一次只读体检：报告中的错误行可双击定位到出问题的模型树节点；全部通过后在工作上下文条确认已选择正确的**应用档案（App Profile）**，再执行运行（F5）。存在阻断问题时提交会被阻止。

## 计算结果怎么导入查看

在**结果（Results）**模块的结果工作窗中点击「导入结果文件」，支持 .e/.exo/.msh/.csv 等格式；也可以在作业工作窗的作业列表中选中已完成的作业，点击「打开结果」直接跳转查看。

## 物理组（Physical Group）从哪里来

物理组在**网格工作窗**的「物理组与网格场」页中创建与管理：可从已加载几何的实体/边界生成，也可随导入网格一并读入；它是材料截面指派、边界条件与载荷作用范围的依据。

## 弹出的属性表单太高怎么办

浮动属性表单可用鼠标拖拽边缘调整大小、拖动标题栏移动位置，软件会记住调整后的尺寸；表单内容超出一屏时右侧会出现滚动条。放弃修改请点「取消」或按 Esc。
