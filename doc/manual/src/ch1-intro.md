# 简介与界面总览

GMP-ISE 是面向有限元分析的集成前处理与作业提交工作台，覆盖从几何建模、材料与物理定义、网格生成到 MOOSE 求解作业提交与结果查看的完整流程。

## 软件定位与应用场景

- 面向科研与工程场景的有限元前处理
- 内置 MOOSE 输入文件生成与远程作业提交
- 草图、部件、装配的参数化建模流程

## 主窗口总览

主窗口由模型树、中央舞台视口、模块工作区与消息控制台组成。

![主窗口总览](images/ch1-main-window.png)

## 模块与工作窗体系

- **Sketch**：二维草图绘制与尺寸约束求解
- **Part**：拉伸、旋转、放样、扫掠等三维特征建模
- **Mesh / Job / Visualization / Results**：独立浮动工作窗承载对应功能

更多操作步骤见 [快速上手](ch2-quickstart.html)。
