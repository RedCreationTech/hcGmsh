# 结果

结果工作窗（Results Workspace）含**结果 / 曲线 / 表格**三个页签，配合可视化工作窗与中央视口完成「导入 → 查看 → 对比 → 导出」的后处理流程。

## 导入结果与任务目录

**结果（Results）**页签管理结果包：

- **导入结果文件...（Import Result File...）**：导入单个外部结果（`.e/.exo`、`.msh`、文本）；
- **导入任务目录...（Import Task Directory...）**：选择作业任务目录，软件自动登记场结果（Exodus）、历史数据（case.csv）、输入快照与日志报告；
- **类型筛选**：全部 / 求解结果（.e/.exo）/ 网格（.msh）/ 文本（.txt/.csv/.log/.yaml），双击条目直接载入视口或文本预览；
- **结果包管理**：**验证结果包（Verify Package）**校验文件完整性，**重新扫描...（Rescan...）**重扫目录登记新文件，**重新定位...（Relocate...）**在目录搬移后修复登记路径，**移到废纸篓...（Trash Project Copy...）**把项目内副本移入系统废纸篓释放磁盘。

## 视口云图与时间步

选中结果后点**在视图中打开**，中央视口加载 Exodus 结果，可视化工作窗控制显示：

- **变量（Variables）**：按 全部/节点/单元 过滤后点选着色变量；
- **标量（Scalar）**：色标预设（蓝-红/灰度/彩虹）、显示方式（表面/线框/表面+边线）、自动或手动色标范围；
- **时间（Time）**：时间步滑块与当前 t= 标签，可自动刷新，拖动即可回放瞬态过程；
- **网格（Mesh）** 页签提供显示开关（面/边/壳/节点/质量）、物理组筛选、透明度与单元收缩；**切片、变形放大、探针**等工具按需启用。

![可视化工作窗标量页：变量、色标与显示方式](images/ch9-viewport.png)

## 曲线：固定、比较与导出

**曲线（Plot）**页签查看时间历程：

- **固定预览曲线（Pin preview）**：把当前跟随视口的预览曲线转为固定曲线，切换变量或时间步后仍保留；图例表逐条列出可见/固定/名称/来源；
- **导入 CSV...（Import CSV...）**：导入外部曲线数据，软件自动识别列并弹出映射对话框（可指定 X/Y 列、单位与倍率）；
- **曲线菜单（Curve ▾）**：移除/编辑选中曲线、**比较 2 条曲线（Compare 2 curves）**做差值对比，也可**新建对比窗口**做多结果并排；
- **导出（Export ▾）**：图表导出 PNG（可选 1×/2×/4× 分辨率）、SVG 或 CSV 数据，或复制图像到剪贴板。

曲线默认跟随视口当前场变量与拾取对象，**聚焦视口**按钮可快速回到视口。

![曲线页签：固定预览、导入 CSV、导出与曲线管理](images/ch9-plot.png)

## 数据表：筛选、分页与列宽

**表格（Table）**页签按行查看当前时间步的实体数值：

- **时间步**：数字框选择步号，**末帧（Latest）**一键跳到最新步；
- **筛选**：按列名、实体号范围、数值范围组合过滤，**清除筛选**一键复位；
- **分页**：上一页/下一页与页码跳转，**行数**可选 50/100/500/1000，**有效位数**控制显示精度；
- **列宽**：各列按比例分摊容器宽度、自动适应窗口，避免末列留白与横向滚动。
