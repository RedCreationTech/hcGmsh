## 6. L-04 实施记录

- 顶部重构为三层：系统菜单栏、五个 30 px 高图标工具组、36 px 高工作上下文条；原 13 个等宽 `QTabBar` 保留为内部兼容状态机但不再可见。
- 菜单统一为 File、Model、View、Mesh、Job、Tools、Settings、Help；原 Demos 收入 Tools，Help 增加 About 入口。
- 常用图标按 Project、Edit、Model、Mesh、Job 拆为五个紧凑组；保存、同步、网格、检查、运行、停止沿用原 `QAction`，Undo/Redo 新增共享 `QAction` 并与草图撤销栈同步启用状态和快捷键。
- 工作上下文条新增模块选择器、只读当前项目和当前对象选择器；模块选择继续驱动原模块页面/工作窗/舞台工具，当前对象按模块映射到模型树根节点并与树选择双向同步。
- 当前对象列表随模型树 CRUD 和模块刷新；Property 跟随当前树对象所属根，Assembly 以 Parts 为当前对象，Visualization/Results 以 Results 为当前对象。
- 新增 L-04 中英文词条；未命名项目和未选择对象按当前语言动态生成，避免刷新后回退为英文。
- 自动验证：构建通过；CTest `1/1` 通过；46 步真实点击 GUI 巡览在 1280×720 下通过顶部高度、8 个标准菜单、5 个工具组、共享 `QAction`、模块切换和对象双向同步断言，并保持 L-03 回归路径通过。

## 7. L-05 实施记录

- Project、Edit、Model、Mesh、Job 五个顶部工具组已启用整组拖拽、浮动和顶部/底部/左侧/右侧停靠；横向和纵向停靠时自动切换紧凑尺寸，组内 `QAction` 顺序不变。
- 新增独立 Display Group，复用现有“切换显示方式、拾取、清除选择、剖切”舞台命令；默认悬浮于中央舞台右上区域，采用紧凑内容尺寸，不以透明覆盖层拦截 VTK 舞台。
- 停靠吸附和预览使用 Qt/操作系统原生行为，保持跨 macOS、Windows、Linux 的平台一致性；需求中的 8～16 px 为可用性建议值，不在应用层重复硬编码平台拖拽阈值。
- 工具组鼠标拖动期间临时关闭舞台拾取，释放后恢复原状态；工具组窗口自身消费拖拽事件，避免相机旋转、平移或误拾取。
- View → Toolbars 可独立显示/隐藏六个工具组，并新增 Reset Tool Layout；重置后五个常用组返回顶部、Display Group 返回舞台右上预置位置且全部重新显示。
- 工具布局使用版本化 `QMainWindow::saveState` 持久化位置、停靠方向和显隐状态；版本不兼容、数据为空或恢复失败时回退默认布局，不触碰项目文件。
- 启动、工具组重新显示、浮动状态变化、屏幕热插拔及可用区域/DPI 变化时都会校验悬浮组位置；越界组自动夹回当前可用屏幕范围。
- 新增自动断言覆盖六组存在性、可移动/可浮动/四向停靠能力、View 菜单显隐同步、Display Group 默认位置以及布局状态的保存/恢复 round-trip。
