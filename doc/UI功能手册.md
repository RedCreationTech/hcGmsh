# GMP-ISE UI 功能手册

> 版本：2026-09-09 v1（对应 P0 弹窗美化后的界面状态）
> 范围：主窗口全部菜单、工具组、工作上下文条、舞台工具栏、导航面板，以及各模块工作窗/弹窗的功能说明。
> 依据：`src/MainWindow.cpp`、`src/StageLeftToolbar.cpp`、`src/GmshPanel.cpp`、`src/MoosePanel.cpp`、`src/VtkViewer.cpp` 等实际代码；中文文案以 `src/L10n.cpp` 为准。

## 2. 菜单栏

## 3. 顶部工具组

| 工具组 | 按钮 | 功能 |
|---|---|---|
| 项目 | 新建 / 打开 / 保存 / 另存 / 截图 | 与文件菜单同源 |
| 编辑 | 撤销 / 重做 | 与工具菜单同源 |
| 模型 | 同步模型到 MOOSE 输入 | 与模型菜单同源 |

| 回放 | 播放 ▶ / 暂停 ⏸ / 终止 ⏹ / 进度条 / 后退 ⏮ / 前进 ⏭ | 多时间步 Exodus 动画：150ms 循环推进（到底回卷）；暂停保持当前帧；终止回第 0 帧；进度条拖动定位（播放/暂停均可）；单步两端钳位不循环。无多步数据时整组禁用并提示原因 |

## 6. 左侧导航区

### 6.1 模型页签

- **过滤框**：按名称过滤树节点，不改变数据；清除后恢复。
- **工作流状态行**：Parts/Materials/Sections/Steps/BC/Loads/Mesh/Jobs 各类节点数量与就绪计数。
- **工具按钮**：添加 / 复制 / 重命名 / 删除（作用于当前选中节点）。
- **模型树**（对象 | 状态 两列）：21 个根节点——Parts、Sketches、Features、Datums、Materials、Sections、Assembly、Physics、Steps、BC、Loads、Interactions、Constraints、Selections、Functions、Variables、Outputs、Mesh、Input Cases、Jobs、Results。
- **状态图标**：失败 ⛔ / 运行中 ▶ / 失效（含引用丢失）/ 成功 ✓ / 已生成 / 不完整 / 未配置 / 就绪 ✓；根节点聚合显示“缺失 (n)/未配置 (n)/不完整 (n)/就绪 (n)”等。
- **右键菜单**：根节点为“添加 \<类型\>、展开/折叠全部”（Mesh/Jobs/Results 多一项打开对应工作窗）；子节点为“编辑属性...（按类型变为打开草图/部件编辑器、打开工作窗等）、复制、重命名、删除”。
- 单击子节点：选择 + 上下文同步 + 舞台高亮；双击：打开对应编辑器/工作窗。

### 6.2 结果页签

- **过滤框** + **结果导航树**（Result/Job | Status）：镜像 Jobs、Results 两个分支。
- 双击 Results 子项载入视口并打开结果工作窗；双击 Jobs 子项打开作业工作窗。
- **右键菜单**：Jobs 根（打开作业工作窗、刷新远程作业）；Results 根（打开结果工作窗、导入结果文件...）；Jobs 子项（打开作业工作窗、远程加“刷新状态”、有 Exodus 输出加“打开结果”）；Results 子项（在视图中打开、复制路径、重命名、删除）。

## 7. 状态栏与底部控制台

- 状态栏左侧：当前上下文（模块 / 对象）；右侧：项目名、保存状态（未保存标记）。临时操作提示在状态栏显示 2~3 秒。
- 底部“作业/消息控制台”：只读，镜像操作日志；Gmsh/MOOSE 运行日志以 `[op] gmsh |` 等前缀转发；可拖高分隔条展开。

## 8. 通用模块工作窗（Module Workspace）

非模态浮动窗，承载草图/部件/属性/材料/截面/装配/分析步/相互作用/载荷 9 个模块的管理页；网格/作业/可视化/结果 4 个模块显示通往专用工作窗的启动器页。

各管理页的统一结构：

| 区域 | 功能 |
|---|---|
| 主操作按钮行 | 模块快捷入口（与上下文条按钮同源），如“打开部件根节点/新建部件” |
| 对象列表 | 当前模块的节点清单，双击定位模型树或打开编辑器 |
| 列表操作行 | 打开所选 / 重命名 / 复制 / 删除 / 刷新 |

### 8.1 属性模块页（PropertyEditor）

| 页签 | 功能 |
|---|---|
| 常规 | 当前节点的类型/状态/名称/摘要表单 |
| 参数 | 快捷参数表单 + 分组应用 + 高级参数表（添加/删除参数、同步模式下拉） |
| 校验 | 全模型校验结果表；可按“仅当前类型/仅有问题”过滤；刷新 / 跳转到节点 |
| 预览 | 节点参数的只读文本预览 |

## 9. 各模块功能与弹窗

### 9.1 草图模块

- 快捷按钮：新建草图（创建后立即进入编辑会话）、打开草图根节点。
- 列表：草图清单，双击进入编辑。
- **草图编辑器**（浮动工作窗，非模态，随舞台 2D 会话）：
  - 工具（互斥）：选择 / 移动 / 直线 / 圆 / 圆弧 / 矩形 / 删除；
  - 约束：水平 / 竖直 / 平行 / 垂直 / 重合；
  - 尺寸：数值输入 + 添加距离 / 添加半径；
  - 反馈行：光标坐标、选中数；底部：撤销 / 重做 / 完成编辑（关闭时自动保存并退出 2D 会话）。
- 舞台左侧工具栏同步显示草图工具组；编辑会话期间禁止切换模块。

### 9.2 部件模块

- 快捷按钮：打开部件根节点 / 新建部件（弹标准对话框选择来源草图）/ 打开网格模块。
- **部件特征面板**（页签化）：
  - 拉伸：草图下拉 + 距离(mm) + “沿 +Z 拉伸”；嵌套闭合轮廓（如矩形内圆）自动生成中空；
  - 旋转：角度(deg) + 绕 Y 轴旋转（草图选择共用拉伸页签下拉）；
  - 放样：第一/第二截面下拉 + Z 向抬升 + 实体放样；
  - 扫掠：轮廓/路径草图下拉 + 沿路径扫掠。
- 部件列表双击打开“部件编辑器 — 名称”工作窗。

### 9.3 材料 / 截面 / 装配 / 分析步 / 相互作用 / 载荷模块

- 均为“快捷按钮 + 对象列表 + 列表操作”管理页；对象编辑经双击或“编辑属性...”打开浮动属性表单（§10）。
- 快捷按钮：材料（打开根节点/新建材料）；截面（打开根节点/新建实体截面）；装配（打开装配/创建装配别名）；分析步（打开根节点/添加稳态/添加静力分析步）；相互作用（打开根节点/添加相互作用）；载荷（打开根节点/添加体力/打开边界条件根节点）。

### 9.4 网格模块 — 网格工作窗（Gmsh 面板）

非模态浮动窗，四个任务页签：

| 页签 | 功能 |
|---|---|
| 模型 | 几何路径与“打开几何/清空模型”；导入后自动剖分、项目加载自动重载几何；实体统计摘要；按维度浏览实体列表；无几何时“使用示例盒 + 尺寸 X/Y/Z” |
| 几何 | 基元（Box/Cylinder/Sphere：原点/尺寸/半径 + 添加）；变换（平移/旋转/缩放，维度+IDs+Pick 选择实体）；布尔（对象/工具 IDs+Pick、保留选项、 Fuse/Cut/Intersect） |
| 分组与网格场 | Physical Groups（组下拉+刷新、维度、名称、实体 IDs+Pick、添加/更新/删除、5 列统计表）；网格场（维度、实体、DistMin/Max、SizeMin/Max、应用/清除/刷新、场列表） |
| 网格 | 网格尺寸、生成维度、按实体尺寸（IDs+Pick/应用/清除）、单元阶次、高阶、MSH 版本、2D/3D 算法、重组合、光顺、优化、输出路径；导出几何 / 生成网格 / 生成 2D / 生成 3D |

- 模块快捷按钮：生成网格 / 生成 2D / 生成 3D / 打开网格根节点 / 生成并提交。
- “Pick”按钮弹实体选择对话框（可勾选列表 + 全选/清空）。

### 9.5 作业模块 — 作业工作窗

非模态单实例浮动窗，两个页签：

**作业列表页**

| 区域 | 功能 |
|---|---|
| 作业控制行 | 运行 / 停止 / 重试 / 打开日志（本地日志对话框 800×500）/ 打开结果 |
| 监控行 | State 状态过滤下拉、刷新、自动刷新（5s，仅远程运行中作业生效） |
| 作业表 | 9 列：名称/状态/案例/进度/开始/耗时/类型/可执行/结果；选中行按本地/远程分流详情 |
| 远程详情 | 刷新 / 取消（二次确认）/ task.md / 日志 / 结果按钮行；进度条与进度文本 |
| 执行详情 | 两列表单：输入/PID/并行/CPU/内存/步数/dt、物理时间/收敛/平均步长/已耗时/ETA/心跳/健康 |
| 制品 | 刷新文件 / 下载选中 + 5 列文件表（远程制品清单与单文件下载） |
| 本地作业 | 本地作业详情只读文本 |

**MOOSE 设置页（MOOSE 面板）**

| 区域 | 功能 |
|---|---|
| 算例设置 | 可执行文件/输入文件/工作目录（各带浏览）；网格路径 + 插入 Mesh Block；Physical Groups 边界列表 + 从分组插入 BCs |
| 执行配置 | mpiexec 开关/MPI 核数/Runner/附加参数；远程作业组：服务器/项目 ID/提交作业/刷新状态/打开远程制品/状态 |
| 输入文件 | 模板下拉（11 项）+ 应用模板 + 状态；`.i` 编辑器；写出输入 / 导出作业快照 |
| 底部 | 运行 / 检查输入 / 停止 |

- 模块快捷按钮：打开作业工作窗 / 补齐流程默认节点 / 同步到输入 / 提交（网格+同步+运行）/ 运行 / 检查输入 / 停止。
- 关闭工作窗不停止作业；重复打开激活已有窗口。

### 9.6 可视化模块 — 可视化工作窗

非模态浮动窗；中央舞台始终显示 3D 场景。

| 区域 | 功能 |
|---|---|
| 顶部按钮 | 聚焦视口 / 显示曲线预览 / 显示表格预览（后两个跳转到结果工作窗对应页签） |
| 文件区 | 当前文件、打开 / 重新加载、输出下拉 + 加载所选 |
| 控制页（导航下拉切换） | **标量**：标量数组、色标预设（Blue-Red/灰度/彩虹）、显示方式（Surface/线框/带边面）、色标位置、自动范围+min/max；**网格**：面/边/壳/节点/质量复选、维度/组/实体/类型过滤、不透明度/收缩、色标条/拾取/清除，底部探针组（开关/点/单元模式/清除/信息）；**视图**：视角预设+应用、坐标轴/外框、重置过滤、拾取信息、分组图例，底部剖切组（开关+轴向+滑块）；**时间**：自动刷新+周期、时间步滑块+当前 t；**变形**：变形开关/向量/缩放，底部向量组（向量数组/自动同步/应用到变形） |
| 变量列表 | 在中央视口左侧（限宽 220）：全部/点/单元过滤，点击切换着色变量 |
| 动画回放 | 用顶部“回放”工具组（§3）：播放/暂停/终止/进度条/单步前进后退 |

- 模块快捷按钮：打开可视化工作窗 / 聚焦视口 / 打开曲线 / 打开表格。

### 9.7 结果模块 — 结果工作窗

非模态单实例浮动窗（可用“新建对比窗口”开额外实例），三个页签：

| 区域 | 功能 |
|---|---|
| 文件操作行 | 打开结果根节点 / 刷新列表 / 导入结果文件...（.e/.exo/.msh/.csv/.txt/.log/.yaml） |
| 视图操作行 | 在视图中打开 / 以文本打开 / 预览（展开文本预览）/ 新建对比窗口 + 类型过滤（全部/求解/网格/文本） |
| 结果列表 | 双击按类型打开；选中显示详情（路径/作业/大小/修改时间/类型/建议动作 + 文本文件前 6 行预览） |
| 预览区 | 默认折叠，Preview 按钮展开 |
| 曲线页签 | ASCII 曲线预览 + 聚焦视口/刷新 + 状态 |
| 表格页签 | 表格行数 + 刷新 + 数据表 |

- 结果对比窗口（Results Compare #N）：多实例，结果列表 + 只读预览 + 刷新列表/聚焦视口，按编号记忆几何位置。
- 模块快捷按钮：打开结果工作窗 / 刷新结果 / 在视图中打开 / 以文本打开 / 打开作业日志。

## 10. 浮动属性表单（节点编辑弹窗）

- 打开方式：模型树双击子节点、右键“编辑属性...”、模型菜单/上下文 Enter。
- 适用对象：模型树所有非根节点（材料/截面/分析步/BC/载荷/相互作用/函数/变量/输出/特征/基准/装配/约束/选择集/输入案例等）。
- **事务语义**：表单在隐藏树克隆（编辑缓冲）上修改；“确定”先校验再一次性写回真树并关闭；“取消”/关闭/Esc 丢弃全部改动，不标记项目已修改。
- 内容：常规 + 参数页签（含快捷参数、分组应用、高级参数表）；校验失败时阻止提交并定位首个错误字段。
- 窗口：模态（打开期间不能切换活动节点）、可移动；默认位于舞台上方偏左；按节点类型记忆尺寸（默认 760×560，最小 560×420），越界时重新居中。
