## 1. 检查清单

### 1.1 模型树（左侧「模型」页）

新建项目后逐行看树根节点图标（16px，深灰，随选中/禁用变色）：

| 节点 | 图标 | 节点 | 图标 |
|---|---|---|---|
| Parts 部件 | 立方体 | Physics | 原子 |
| Sketches 草图 | 方框笔 | Steps 分析步 | 有序列表 |
| Features 特征 | 多立方体 | BC 边界条件 | 角框方块 |
| Datums 基准 | 锚 | Loads 载荷 | 挂钩砝码 |
| Materials 材料 | 烧瓶 | Functions 函数 | 波形 |
| Sections 截面 | 裁剪 | Variables 变量 | 根号变量 |
| Assembly 装配 | 拼图块 | Outputs 输出 | 文件导出 |
| Constraints 约束 | 锁 | Interactions 相互作用 | 链环 |
| Selections 选择集 | 十字准星 | Mesh 网格 | 网格格 |
| Input Cases 输入算例 | 文件导出 | Jobs 作业 | 公文包 |
| Results 结果 | 折线图 | | |

检查点：① 每行图标语义可辨认、风格统一；② 选中行图标变蓝（高亮蓝 #2f6fed）；③ 树操作行 4 个小按钮（＋添加／复制／笔-重命名／垃圾桶）带中文 tooltip。

### 1.2 状态列（模型树第二列）

作业类节点的状态小图标（14px）：✓=成功、▶=运行中、■=失败、回环=未配置/生成中。新建作业跑一遍或刷新作业列表验证。

### 1.3 结果导航树（左侧「结果」页）

Jobs / Results 两个根节点图标（公文包／折线图）。导入一个结果文件验证子节点显示正常。

## 2. 重点裁定

树节点图标是实施方按语义选定的（映射表见 `src/IconFactory.cpp` 的 `tree_*` 段），语义不合的可直接点名更换，例如：Constraints 现用「锁」、Input Cases 与 Outputs 同为「文件导出」（若介意可给 Input Cases 换 `file-code`）。

## 3. 反馈格式

逐项「通过/不通过」；不通过注明：树节点名、当前图标、期望方向。
