## 2. 通用检查点（每个弹窗都适用）

1. 所有按钮**图标居左、文字在右**，图标与文字间距自然（约 6px）。
2. 图标颜色随文字色（深色图标配黑字），**禁用按钮的图标同步变灰**——重点找一个禁用态按钮确认（如 Job 作业表未选作业时的「停止」）。
3. 图标清晰不模糊（Retina 屏下应锐利，字体字形自动适配 HiDPI）。
4. 按钮原有**文字、tooltip、点击行为全部不变**——抽 2~3 个按钮点击验证功能正常。

## 3. 分窗检查清单

### 3.2 Mesh 工作窗（4 个一级页签 × 子页签）

- 模型：打开几何/清空模型/刷新
- 几何›基元：添加基元（方块）；几何›变换：拾取（十字准星）/平移/旋转/缩放；几何›布尔：两个拾取 + 合并/剪切/求交
- 分组与网格场›物理组：刷新/取消舞台筛选/拾取/添加/更新所选/删除所选；网格场：拾取/应用场（对勾）/清除场（橡皮）/刷新
- 网格：拾取/应用/清除/选择输出/导出几何/生成齿轮图标/生成2D网格/生成3D网格

### 3.3 Job 工作窗

- 作业列表：运行(▶)/停止(■)/重试/打开日志/打开结果/刷新 + 详情区 取消/task.md/日志/结果 + 制品区 刷新文件/下载所选
- MOOSE 设置›算例设置：3 个拾取 + 插入网格块/从物理组生成边界；执行配置：提交作业(纸飞机)/刷新状态/打开远程制品；输入文件：应用模板/校验并预览合并/写出输入/导出任务快照
- 底部通栏行：校验工作流/运行/检查输入/停止

### 3.4 Visualization 工作窗

- 顶部：聚焦视口(靶心)/显示曲线预览/显示表格预览 + 打开/重新加载/加载所选
- 网格页两处「清除」(×)；视图页：应用视角(眼睛)/重置过滤器；变形页：应用到变形

### 3.5 Results 工作窗

- 结果页两行按钮：根节点/刷新/导入文件/导入任务目录/验证结果包 + 废纸篓/重新定位/重新扫描/视图中打开/文本打开/预览/对比窗口
