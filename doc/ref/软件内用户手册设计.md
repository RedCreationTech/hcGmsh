## 1. 决策记录

| # | 决策点 | 结论 |
|---|---|---|
| Q1 | 技术载体 | Qt Help Framework（QtHelpEngine，类 CHM：目录/索引/搜索，.qch 离线包，内嵌应用窗口） |
| Q2 | 媒体能力 | 静态截图（PNG/JPG 内嵌 qch）；极少数外链视频（系统浏览器）；不做动图；若视频需求增长，HTML 内容源与 QWebEngine 方案共用仅换壳 |
| Q3 | 内容组织 | A+B 混合：manual/用户手册.md 重组为正式帮助文档（专业软件帮助语调），人工算例操作说明独立为教程章；每章开头"快速入门"任务卡片；既有资料仅作参考、**截图全部按最新 UI 重截**；开发视角内容不入册；主线：单功能 → 关联功能流程 → 完整案例；规模 60~80 页、单页一主题 |
| Q4 | 窗口形态 | 独立非模态顶层窗（复用现有工作窗机制）：左目录/索引/搜索 + 右 QHelpBrowser；帮助菜单"用户手册" + **F1** 快捷键；上下文跳转章节留接口（anchor 命名规范先行，二期实现）。**2026-09-27 修订**：手册窗用 Qt::Window 普通顶层窗（与主窗口同级、原生标题栏双击 zoom 适配屏幕）；其余工作窗仍 Qt::Tool + 吞标题栏双击防护（Qt::Tool 的 macOS zoom 会丢标题栏，实证） |
| Q5 | 搜索取舍 | 目录 + 手工关键词索引为主（QtHelp 索引文件精确命中中文词条），不自建中文分词；页数纪律兜住查找成本。**2026-09-27 增补（Q-S1）**：搜索页实现"全文纯文本子串搜索"——构建期由 tools/build_manual.py 同步生成 searchdata.json（数组 [{url,title,text}]，text=HTML 去标签纯文本、压缩空白），作为资源文件登记进 .qhp 打进 qch（manual/ 虚拟目录，图片不入数据）；运行时经 QHelpEngine::fileData 读取，仅首次搜索解析一次并缓存；输入 300ms 防抖后对每页 text 做大小写不敏感子串计数，结果按命中数降序列出「标题（命中 N 次）— 命中处前后 ~30 字摘要」，点击结果跳页并 find() 高亮首个命中。明确不做中文分词/相关性排序 |
| Q6 | 截图资产 | 先出《截图清单》（章节×截图名×界面状态）；总览类复用 GMP_UI_AUDIT 批量采集；操作类人工截（统一 1100×750、统一演示项目数据）；存 doc/manual/images/；重截命令入 AGENTS.md 速查 |
| Q7 | 双语策略 | 首期只做中文；写作规范：控件名首次出现「中文（English）」、之后用中文；qch 多 namespace 预留英文版 |
| Q8 | 构建链与打包 | 手册源 = Markdown（doc/manual/ 章节 md + images/ + 手册目录.yml）；构建期 vendor Python 脚本 md→HTML → qhelpgenerator 打 .qch → **qrc 编译进二进制**；GitHub Actions Windows 打包 workflow 零改动（前提：CI Qt 含 Qt Tools 的 qhelpgenerator，开工时验证）；手册更新 = 改 md 重新构建；谁改 UI 谁重截对应截图（义务写进 AGENTS.md） |

## 2. 手册章节结构（v1 草案，实施时可调）

```
1. 简介与界面总览
   1.1 软件定位与应用场景      1.2 主窗口总览(截图)        1.3 模块与工作窗体系
   1.4 项目/语言/应用档案      1.5 工具栏与快捷键总表
2. 快速上手（案例导向薄章）
   2.1 十分钟完成第一个算例    2.2 演示项目说明
3. 建模（单功能条目，按模块树序）
   3.1 草图(工具/约束/尺寸)    3.2 部件(拉伸/旋转/放样/扫掠) 3.3 特征与基准
   3.4 装配实例                3.5 参数化对象与属性表单
4. 材料 · 截面 · 物理
   4.1 材料(通用/CDP)          4.2 截面指派               4.3 Physics 与输出变量
5. 分析定义
   5.1 分析步(静力/瞬态/预设)  5.2 函数                   5.3 边界条件与载荷
   5.4 相互作用               5.5 约束与选择集
6. 网格
   6.1 模型/几何(基元/变换/布尔) 6.2 物理组与网格场        6.3 网格生成
7. 作业与远程提交
   7.1 算例设置与浏览          7.2 执行配置(MPI/远程)     7.3 输入文件(生成/自定义/报告)
   7.4 作业监控与制品下载
8. 结果（Results 工作窗）
   8.1 结果导入(文件/任务目录) 8.2 云图与视口            8.3 曲线(固定/比较/导出)
   8.4 数据表(筛选/分页)       8.5 结果包管理(校验/复制/失联)
9. 教程：V01 单轴拉伸完整复现（源自人工算例操作说明，逐步截图版）
10. 常见问题(FAQ)与故障排查
```

anchor 规范：`ch<N>-<section>-<topic>`（如 `ch5-1-transient-step`），上下文跳转接口（二期）按此锚点定位。

## 3. 实施步骤（开工顺序）

1. **地基**：doc/manual/ 目录骨架 + 手册目录.yml + vendor md→HTML 转换脚本 + CMake 打 qch 入 qrc + Help 工作窗（菜单/F1）+ 巡览合同（打开手册窗口、目录加载断言）——本步完成即可在软件内打开空壳手册；
2. **内容**：按 §2 章节写 md（先 1/2/3 章），每章交付后定向巡览 + 人工验证手册；
3. **截图**：截图清单 → 批量采集 + 人工补截 → 嵌入对应章节；
4. **验收**：全量巡览 + CTest + 人工按手册操作抽验 2~3 个任务（按手册步骤能独立完成操作即合格）；
5. **收尾**：AGENTS.md 补重截义务与速查行；推送。

## 4. 验收标准

- 软件内 F1/菜单可打开手册窗口，目录/索引中文可用；
- 60~80 页、三层结构完整，截图与当前 UI 一致；
- 抽验：新用户按"快速上手"章可完成演示算例全程；
- GitHub Actions Windows 产物 exe 内含手册（打开即用，无外部文件）。
