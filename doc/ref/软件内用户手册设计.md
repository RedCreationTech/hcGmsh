## 3. 方案细节（已确认部分）

### 3.1 技术路线（Q1/Q2）

- QtHelpEngine + QHelpBrowser 内嵌为应用内窗口；菜单入口：帮助 › 用户手册（现有 About 旁）。
- 内容以 HTML 子集编写，编译期打进 `.qch`（压缩包，含图片资源），随应用离线分发。
- 图片：`<img>` 内嵌；视频：外链系统浏览器。
