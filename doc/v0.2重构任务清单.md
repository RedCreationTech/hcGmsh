## 0. 重构总原则

1. **行为冻结优先**：以 113 步全量真实点击巡览 + CTest + Phase 5 G1 静态证据为回归基线；任何重构任务完成后基线必须全绿，且全量巡览基线只增不减。
2. **绞杀者模式**：先建新接口/新层并从现有类抽逻辑，保留原文件 wrapper，测试稳定后再移动文件；不第一天就搬目录、不做大爆炸重写。
3. **兼容红线**（doc/ref/03 §18）：继续读写 `.gmp.yaml` schema v2；不改变工程路径规则；不破坏 Phase 4/5 工程与验收结论；Profile/Mapping/Snapshot v2/LIMS API 保持兼容；旧 Feature 历史可读。
4. **保护资产清单**（doc/ref/05 §5）：SketchDocument、PlaneGCS、OCC、PhysicalGroupManifest、ApplicationProfile、MooseMappingRegistry、Snapshot v2、Runner 接口、SimClient/LIMS 边界、Schema 版本化、Phase 5 验收体系、Feature 历史、Assembly owner+bbox 恢复策略——提升层次、明确边界、保留兼容，不重写。
5. **测试纪律**（沿用 AGENTS.md）：日常修改跑 1～2 个定向巡览；每个任务提交前跑全量巡览 + CTest；每个 Stage 准出跑全量巡览 + CTest + 相关人工证据复核。
6. **与 Phase 5/6 的关系（2026-09-18 用户裁决）**：此前全部计划任务（G2/G3/P6，含 G2 支持矩阵分析）在 v0.2 期间**一律暂停**；G1-08/09 的远端证据保持“环境待测/延期”记录，不阻塞重构，也不作为并行计划任务。**G1 已验收功能（装配、Physical Groups、材料/Section、Physics/Step、Contact/BC/Load 映射、确定性生成、快照等）为重构零回归红线**：每次提交全量巡览 + CTest 把关，任何既有功能退化立即回退该提交，不接受“先合后修”。
