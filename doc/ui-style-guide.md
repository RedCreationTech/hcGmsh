# GMP-ISE UI 视觉规范（ui-style-guide）

> 版本：2026-09-06 v1（Phase 3 / V-01 建立）
> 用途：统一全局视觉层级、密度与图标语言；作为与 Abaqus 参考截图逐区对照的基准。
> 实现位置：主题样式表 `src/MainWindow.cpp::apply_theme()`；自绘图标 `MakeIcon(IconGlyph)`；舞台工具栏 `src/StageLeftToolbar.cpp`。

## 1. 设计原则

对标 Abaqus/CAE 的成熟工程软件观感，但不复制其任何美术资源：

1. **浅灰原生工作台**：菜单、工具区、树、表单使用浅灰白体系，靠 1 px 分隔线而不是投影或卡片区分层级。
2. **深色舞台**：中央 3D 舞台保持深色背景，模型、网格线、标注、选择高亮在其上必须可辨识。
3. **紧凑密度**：图标为主、文字为辅；工具区分组间距大于组内间距；不保留开发期字母/文字占位按钮。
4. **蓝色选中反馈**：选中态统一为蓝色系（`#2f6fed` / `#dbe7ff`），禁用态灰化且可辨识。
5. **克制的表单层级**：表单使用标准标签—字段对齐、页签、分组框和底部操作按钮，不使用大面积装饰卡片。

## 4. 分区规范

### 4.1 顶部三层（菜单栏 → 图标工具组 → 工作上下文条）

- 菜单栏是完整命令入口；菜单项、快捷键、工具按钮复用同一 `QAction`。
- 图标工具组按 项目/编辑/建模/网格/作业 分组，独立拖拽、浮动、磁吸；组间有清晰分隔。
- 工作上下文条：模块选择器、当前项目（只读）、当前对象选择器；1280 px 宽度下关键字段必须可见。

### 4.2 左侧导航区

- Model/Results 两个页签；过滤框内嵌原生清除按钮；“对象/状态”列可拖动调宽。
- 树节点状态用图标 + 文字共同表达（不只依赖颜色）：未配置/不完整/就绪/失效/已生成/运行中/成功/失败。

### 4.3 舞台与舞台左侧工具栏

- 舞台左缘垂直工具栏默认 32–48 px 宽，图标 20 px、热区 36×34 px；通用工具常驻，模块工具按上下文切换；可折叠为单按钮。
- 方向标、坐标轴、选择反馈固定在舞台边角，不遮挡模型主体。
- 互斥工具显示选中态（蓝底白字 `gmpSketchTool:checked`），禁用态灰化。

### 4.4 底部区

- Console/作业消息默认紧凑，可展开；操作日志（带时间戳）与状态消息分离。

### 4.5 浮动工作窗与表单

- 工作窗（Mesh/Job/Visualization/Results/Module）统一标题栏、尺寸记忆、越界恢复；最小尺寸保证内容可用。
- 属性表单：模态浮动表单，标签—字段同排，页签（常规/参数/校验/预览），底部 确定/取消；确定写回、取消丢弃。
- 长表单只在所属任务页保留单层按需滚动，禁止嵌套滚动。

### 4.6 作业监控与列表

- 表格表头浅灰加粗、行选中 `#dbe7ff`；状态列文字与树状态词汇一致（Queued/Running/Completed/Failed/Canceled/Generated）。
- 详情面板用 GroupBox 分区（Execution Details / Artifacts），键值对标签右对齐。

## 5. 图标语言

- 全部图标为项目**自绘矢量字形**（`IconGlyph`，30 个）或许可证兼容资源；禁止直接复制 Abaqus 图标，禁止字母占位。
- 尺寸按第 3 节；同一区域内图标风格、线宽一致。
- **每个图标按钮必须有 Tooltip，包含功能名和快捷键**（无快捷键时注明“无快捷键”）。
- 互斥工具必须有视觉选中态；仅图标表达状态时 Tooltip 必须可解释该状态。
- 树节点使用语义图标（Part/Material/Mesh/Job/Result 等）+ 状态列图标，不依赖颜色。

## 7. 可访问性基线（细化在 V-02）

- 100% 与 150% 缩放下无文字截断、按钮重叠、浮窗越界、图标模糊。
- 状态表达不只依赖颜色：图标 + 文字 + Tooltip 共同表达。
- 键盘可达：Tab/Shift+Tab 遍历表单，Enter 触发默认按钮，Esc 取消。

## 8. V-01 验收检查表

- [ ] 全部图标按钮 Tooltip 含功能名与快捷键（或无快捷键说明）。
- [ ] 无字母/文字占位图标。
- [ ] 视觉层级：菜单栏、工具组、工作上下文条、左树、舞台、底部区清晰可辨。
