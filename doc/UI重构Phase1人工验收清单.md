> 当前验收范围：L-01“两栏主工作区与兼容承载窗口”

> 结论规则：以下 4 项全部通过后，L-01 才可标记完成并进入 L-02。

## TEST-P1-L01-01 两栏布局与舞台占比

1. 启动应用并关闭所有浮动窗口。
2. 将主窗口内容区调整为约 1440×900。
3. 确认主内容区只有左侧模型树和中央舞台，不存在永久右侧属性区域。
4. 确认左树默认宽度下，舞台宽度不低于主内容区的 75%。
5. 横向放大主窗口，确认新增宽度优先分配给中央舞台。

通过标准：无右侧占位；中央舞台始终可见且满足宽度要求。

## TEST-P1-L01-02 兼容工作窗入口与树选择行为

1. 保持 Module Workspace 关闭。
2. 单击模型树中的 Material、Step、Load 等节点。
3. 确认树选择和模块上下文发生同步，但不会自动弹出 Module Workspace。
4. 显式点击顶部 Material、Step、Load 等模块页签，确认工作窗打开、置前并显示对应页面。
5. 关闭工作窗后，通过 View → Module Workspace 再次打开。

通过标准：树单击不打断舞台操作；两种显式入口均可恢复工作窗；切换页签时页面对应正确。

## TEST-P1-L01-03 浮动窗口与舞台独立性

1. 打开 Module Workspace，将其拖到主窗口右上方或第二块屏幕。
2. 调整工作窗大小，并依次切换 Part、Mesh、Job、Visualization、Results。
3. 关闭工作窗，确认中央舞台没有留下空白占位。
4. 再次打开工作窗，确认其为非模态窗口，主窗口和舞台仍可点击操作。

通过标准：工作窗可移动、缩放、关闭和恢复；关闭不销毁页面；舞台不被永久挤占。

## TEST-P1-L01-04 布局状态恢复

1. 调整左侧模型树宽度和底部 Console 高度。
2. 调整 Module Workspace 的位置与大小，并保持其打开。
3. 正常关闭后重新启动应用。
4. 确认主窗口尺寸、左栏宽度、Console 高度、工作窗位置/大小和可见状态均恢复。
5. 关闭工作窗后再次正常退出并启动，确认工作窗保持关闭。

通过标准：两次重启后的布局状态分别与退出前一致，且不存在屏幕外无法找回的窗口。
